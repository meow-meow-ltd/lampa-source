## 2. О9 — чому саме ці версії

- **`totp-rs = 5.7.2`** — остання 5.x (2026-06-23). План фіксує 5.x; 6.0.0 — новий
  major (edition 2024, інший API), тому не беремо. `default = []` → без
  `otpauth`/`qr`/`serde`/`gen_secret`, дерево мінімальне. Профіль TOTP
  (SHA-1/6/30/window=1) задається аргументами `TOTP::new`, а не фічами; вектори
  перевірятиме T10 проти speakeasy/RFC 6238. Транзитивні: `hmac 0.12.1`,
  `sha1 0.10.7`, `sha2 ^0.10` (уніфікується з нашим `=0.10.9`, без дубля
  `sha2`), `base32 0.5.1`, `constant_time_eq 0.3.1`, `digest 0.10.7` (уже був).
- **`sha2 = 0.10.9`** — 0.10.x-кандидат плану; вже був у `Cargo.lock`
  транзитивно (через `sqlx`), тепер піднятий до прямої залежності **без зміни
  версії** → одна реалізація SHA-256 для Rust; Node-парність забезпечується
  `hex::encode` (lowercase) у T10.
- **`rand = 0.8.5`** — CSPRNG `rand::rngs::OsRng` (поверх `getrandom 0.2.17`) для
  32-байтних токенів. Обрано 0.8.x, а не 0.9.x, бо API `OsRng` стабільний і
  очікуваний для коду T10 (`RngCore::fill_bytes`); 0.9 змінює контракт
  (`TryRngCore`). Транзитивні: `rand_core 0.6.4`, `rand_chacha 0.3.1`,
  `getrandom 0.2.17`, `ppv-lite86 0.2.21`.
- **`hex = 0.4.3`** — уже був у lock транзитивно; піднятий прямо, версія не
  змінилась.
- **`rusqlite = 0.32.1`, `default-features = false`, `features = ["backup"]`** —
  єдина 0.3x-версія, чий `libsqlite3-sys ^0.30.1` **збігається** з `sqlx 0.8.6`
  (той самий `libsqlite3-sys 0.30.1`, `bundled` через `sqlx-sqlite`), тому в
  дереві один SQLite і одна bundled-збірка, без системної `libsqlite3`. Default
  features вимкнені → немає `bundled`/`session`/`hooks`/`functions`/`vtab`
  тощо; єдина увімкнена фіча — `backup`. Транзитивні: `hashlink 0.9.1`,
  `hashbrown 0.14.5`, `ahash 0.8.14` (тягне `getrandom 0.4.3`),
  `fallible-iterator 0.3.0`, `fallible-streaming-iterator 0.1.9`. Записи
  `wasm-bindgen`/`js-sys`/`bumpalo`/`r-efi`/`rustversion` — target-only
  (wasm32/uefi) залежності `getrandom 0.4.3`; на linux-gnu не компілюються.
- **`[lints.cargo] unused_dependencies = "allow"`** — T15 ставить піни **до**
  того, як T10/T11 почнуть використовувати крейти, тож cargo manifest-lint
  (`cargo::unused_dependencies`, default `warn`) інакше дає 4 попередження і
  засмічує zero-warning gate хвилі. Таблиця локальна для пакета; rustc/clippy
  далі працюють з `-D warnings`. Прибрати, коли всі 5 крейтів будуть у коді
  (T10/T11).

## 6. Нотатки для T10 / T11

- **T10**: `totp-rs 5.7.2` з порожніми default features — профіль задається
  аргументами (SHA-1, 6, window=1, 30 с); `sha2 = 0.10.9` + `hex = 0.4.3` дають
  `hex::encode(Sha256::digest(...))` (lowercase, 64 символи — як Node);
  `rand = 0.8.5` — `rand::rngs::OsRng` + `fill_bytes` для 32 байт.
- **T11**: тільки `rusqlite`-фіча `backup` (`rusqlite::backup`), джерело
  відкривати read-only (`mode=ro`) за `docs/decisions.md`; весь код — у
  `server/src/db/backup.rs`; default features не вмикати (інакше з'явиться
  друга конфігурація SQLite).
- Нові залежності у W1 — лише через T15/капітана (єдиний власник Cargo-файлів);
  після додавання — обов'язковий `--locked` прогін чек-чейну.
